U-AUGUST yinyanga okuqwashiswa ngayo abantu ngokubaluleka kokunakekelwa kwamazinyo kanti kuningi okusifundisa ngako. Abantu abawanakekeli amazinyo kanti uhlelo esinalo lwezempilo alusikhuthazi ngokwanele ngokunakekelwa kwawo nokwenza kube semqoka ukuba abazali bafundise izingane ngokunakekela amazinyo nezinsini...
Ukunakekelwa kwamazinyo
Kunabazali abacabanga ukuthi akubalulekile ukuqikelela ukuthi amazinyo engane ayanakekelwa ngoba ayaphuma awokuqala kumile aqine njengawabantu abadala.
Odokotela bamazinyo bayagcizelela ukuthi ingane kumele iqale ukuxubha amazinyo kusamile elilodwa vo - ixubhe njalo emva kwesidlo sasekuseni nakusihlwa ngaphambi kokulala.
Ngokomthetho ingane ayixubhe njalo emva kokudla ukuze kungakheki i-plaque noma kubole amazinyo.
Ingane isuke isikulungele ukuhlolwa amazinyo uma isineminyaka emithathu kanti lokho kumele kwenziwe njalo ezinyangeni eziyisithupha kuya kwezingu-12.
Izixubho zodado Kunezixubho eziyisipesheli ezenzelwe izingane. Zihlukile kwezabadala - amazinyo azo athambile kanti ziziphatha kahle izinsini zezingane, usayizi wazo wenza zibambeke kalula. Lezi zixubho zimi ngezindlela ezihlukene, zinemibala ehlukene kanti kumele zisetshenziswe nomuthi wezingane ongenayo i-fluoride eningi.
Waqinise
Sekuphele iminyaka odokotela betshela abazali ukuthi i-calcium ikahle ekuqiniseni amathambo namazinyo. Kodwa lokho akusho ukuthi kumele unike ingane amaphilisi ane-calcium ngoba ikhona ekudleni okuningi.
Imikhiqizo yobisi ine-calcium eningi ngakho qiniseka ukuthi ingane iyayithola ngokuyinika ingilazi yobisi, ucezu lukashizi noma i-yogurt encane.
Gwema i-yogurt efakwe ushukela ngoba ingawabolisa amazinyo. Khetha esashukela ngokwendalo.
Ama-veg anjengesipinashi ne-broccoli, nawo ane-calcium, kanti nenhlanzi (enjengo-sardine) ine-calcium.
Ukuvimbela ukubola kwamazinyo
Ukudla okunama- carbohydrates yikona okubolisa amazinyo ikakhulu uma enganakekelwa kahle. Ukugwema lokho, umndeni wonke mawuxubhe amazinyo kanyekanye ukuze ubheke ukuthi axujwa kahle yini.
Ukugwema ukudla okunoshukela:
n Ungaziniki izingane uswidi neziphuzo ezihlohlozayo. Ziphuzise ubisi namanzi.
n Uma ufuna ukuzithokozisa ngoswidi, zitshele ukuba zixubhe amazinyo emva kokuwudla.
n Ujusi wezithelo ukahle enganeni kodwa awuwalungele amazinyo engane ngoba uhlala isikhathi eside emazinyweni engane. Ingane mayixubhe amazinyo emva kokuwuphuza.

OKWENZEKA ukhulelwe kuyashiyana kulowo nalowo mama. Ziningi izinto ezingaba nomthelela esisindweni esengezeka ukhulelwe nesisindo sengane.
Abanye bahlushwa wukuthi isisindo sabo sizokhuphuka uma bekhulelwe kanti abanye bahlushwa wukungakhuphuki kwaso ngokwanele okungaba yinkomba yokuthi ingane ayikhuli kahle esibelethweni.
Akufanele uzihluphe ngokukhuphuka kwesisindo sakho kanti ungalokothi ucabange ukushintsha indlela odla ngayo ngoba lokho kungaba yingozi enganeni engakazalwa.
Isisindo somuntu okhulelwe sivame ukukhuphuka ngo-13,5kg. Sikhuphuka ezinyangeni ezintathu ukhulelwe kanti indlela odla ngayo inomthelela omkhulu kulokho.
Abanye omama abakuthandi ukudla kanti abanye badla kakhulu.
Uma uqala ukuyoxukuzwa, umbelethisi noma udokotela uyakukala ngoba yisisindo sakho esizocacisa uma kukhona inkinga onayo ukhulelwe.
Omama abakhulelwe abanesisindo esikhulu noma esiphansi basengozini yokuphathwa yisifo sikashukeIa, i-high blood pressure, babelethe ngokuhlinzwa noma ngaphambi kwesikhathi.
Ukubheka isisindo
Njalo uma uyoxukuzwa, kukalwa isisindo nesisu sakho. Lokho kwenzelwa ukuqinisekisa ukuthi ingane ikhula kahle. Uma konke kusafana nangamhla uqala ukuyoxukuzwa, uyahlolwa kubhekwe izinkinga ingane okungenzeka ukuthi inazo.
Okunye okungathikameza isisindo sengane yizifo ezinjengesifo sikashukela esingenza isisindo sengane sikhuphuke kakhulu.
Uma uyoxukuzwa, umbelethisi uhlola igazi ukuze athole ukuthi ngabe ingane yinkulu ngokwemvelo yini noma yinkulu ngenxa kashukela.
Ukubhema nokuphuza ngesikhathi ukhulelwe kungasehlisa isisindo sengane. Uma izalwe inesisindo esiphansi ingagula.
Utshwala bungenza ingane ibe neFoetal Alcohol Syndrome (FAS) isifo esiyenza ibe ntekenteke ngenxa yokuphuza ukhulelwe kanti ingakhubazeka.

Fasa ibhande
Ukuphepha emgwaqweni kusho ukufasa ibhande lesihlalo sakho. Nezingane zidinga ukuphepha uma zisemotweni. Izimoto zinamabhande afaswayo ngisho nasezihlalweni ezingemumva imbala. Nezingane kumele zifase amabhande kanti ezincane kumele zibe nesihlalo emotweni ukuqinisekisa ukuthi ziphephile ngoba amabhande asemotweni enzelwe abadala.
Uma uthenga isihlalo sengane sasemotweni qiniseka ukuthi uyazibheka lezi zinto:
n Mazibe namabhande abanzi namahhanisi. Mazibe namabhande amagxalaba, amathanga nelilodwa elingena phakathi kwemilenze yengane.
n Kumele lifaseke kalula. Uma udideka, ungagcina usulifake ngendlela engafanele nokuyinto engabeka ingane engozini uma kwehla ingozi.
n Isihlalo esinama-pads siyiphatha kahle ingane.
n Qiniseka ukuthi sinamakhava ongawawasha.
n Khetha isihlalo esihambisana neminyaka yengane.Izihlalo zemoto zihlukaniswe ngokwesisindo sengane - ezezingane ezizelwe kuye kwezingu-22kg no-36kg (wezingane zeminyaka engu-12, ubude bazo obungaphansi kuka-1,5m).
IZINGANE zihlupha ngokukhala kanti lokho kuyindlela ezixhumana nawe ngayo. Izingane azikhaliswa yizinhlungu kuphela noma ukungaphatheki kahle kodwa zikhaliswa wumzwangedwa zifune ukunakwa.
Okokuqala okumele ukwenze uma uyithulisa wukubheka ukuthi ayikhaliswa yini wukulamba noma wubumanzi benabukeni noma wukulala kabi nokugula.
Uma iqhubeka ikhala phezu kokuba usukubheke konke lokhu, zama lezi zinto ezingayithulisa:
n Yigone. Izingane eziningi ziyathanda ukugonwa. Lokho kuzinika isibindi kanti kwenza nazane kahle nengane. Umama nobaba bangakwenza lokhu - ucwaningo lukhomba ukuthi izingane ziyazwana nomsindo wokushaya kwenhliziyo yakho ngesikhathi zibekwe esifubeni.
n Nyakaza. Yigone uzulazule nayo endlini. Ungayibeletha, uyifake kwi-pram noma kwi-stroller uphumele ngaphandle nishaywe wumoya.
n Cula noma ukhulume nayo. Ingane yakho iyathanda ukukubuka ebusweni kanti uma uvula umlomo ingakhohlwa wukukhala igxile entweni oyishoyo kwenzeke kube khona ezokusho nayo. Ukucula amaculo okuyithuthuzela kungayithulisa ikakhulu uma ucula iculo owawulicula ukhulelwe.
n Yiphulule. Lokhu kuyikhambi ezinganeni eziqaqanjelwa yisisu ngoba kudambisa izinhlungu. Fudumeza izandla ugcobe uwoyela uyiphulule isisu kahle.
n Yisize uma ingaphathekile kahle. Uma ikhala emva kokudla kungenzeka ukuthi isisu sayo sinomoya. Yibeke ehlombe uyihlikihle emhlane. Uma ingalele kahle, shintsha indlela elele ngayo ubheke ukuthi ayizweli yini ukushisa ngoba umzimba wengane awukwazi ukulawula ukushisa njengowomuntu omdala.
n Ungayihluphi uma ikhathele. Uma ibukeka ikhathele ingane yakho, ungayiniki abanye abantu ngoba lokho kungenza ikhathale kakhulu igcine isikhala.
n Iyise kudokotela. Uma igula noma ikhala kakhulu, yiphuthumise kudokotela. Ngaleyo ndlela kuzobonakala uma kungukuthi kukhona ezinye izinkinga ezidinga ukuba yelashwe.
