zulu.2232.parenting
Ukusebenzisa ipowa
ASIKHO isikhathi esingathi sikahle ekufundiseni ingane ukusebenzisa ipowa - konke kuncike enganeni. Kodwa izingane eziningi zifunda ukuyisebenzisa sezineminyaka emibili - emithathu ziyihlanganisa sezifunde kahle.
Izimpawu okumele uzibheke
Ngaphandle kweminyaka, ezinye izinto okumele uzibheke zincika ekukhuleni kwengane. Ukuze iyisebenzise kahle ipowa, kumele yazi imithetho yokusetshenziswa kwayo.
Kufanele ifunde ukuhlala kuyona ibuye isukume, ifunde ukukhumula nokugqoka okwangaphansi.
Kufanele ihlukanise phakathi kokuphiswa wumchamo nokuzikhulula.
Ezinye izimpawu ongabona ngazo uma isikulungele ukusebenzisa ipowa wukuthanda ukubuka wena noma izingane zakubo uma zisebenzisa indlu yangasese, noma kube ezokwenza uma inabukeni limanzi noma lingcolile. Ngabe iyawazi umehluko phakathi kwenabukeni elingcolile nelihlanzekile?
Nakhu ongabona ngako uma isikulungele. Uma idlala engadini ingagqoke nabukeni bese iyachama, ngabe iyazi ukuthi umchamo ophansi uphuma emzimbeni wayo?
Ukuqala
Kuhle uyifu-
ndise ukuse-benzisa ipowa ngesikhathi igeza. Chaza ukuthi yini umsebenzi wepowa uyitshele ukuthi ayihlale kuyona ukuze izwe ukuthi iyiphatha kanjani. Uma ichama, yincome. Uma isichamile, izothanda ukuyisebenzisa. Yikhuthaze iyisebenzise njalo kodwa ungayiphoqi uma ingathandi. Yilinde ize ilungele ukuyisebenzisa.
Izingane ezikhonze ukudlala ngeke zifune ukuchitha isikhathi epoweni, kodwa uma uzoyifundela noma uphenye incwadi nayo ngesikhathi iyisebenzisa, izokhululeka ihlale kuyona.
Yijwayeze ipowa
Uma usukwazi ukuyihlalisa ekhaya ngaphandle kwenabukeni, yijwayeze ipowa. Ipowa kufanele ihlale e-bathroom - kodwa kuhle uyibeke eduze kwalapho idlala khona ukuze iyikhumbule.
Bekezelela ukuphunyuka
Ingane yakho isiyakwazi ukusebenzisa ipowa kanti ayisafuni ukufaka amanabukeni! Zinhle lezo zindaba, kodwa khumbula ukuthi ingozi iyenzeka ngoba izingane ziphazamiseka kalula ngoba zihlala zimatasa. Ngezinye izikhathi izophunyuka, kodwa akufanele uyijezisele lokho. Lokho kuseyingxenye yokufunda futhi ngeke kuthathe isikhathi eside kakhulu.
Izinsuku ezinhle nezimbi
Ngezinye izikhathi kuzokwenzeka ukuthi kuphele izinsuku ipowa ingenalutho emva kokuba ingane isifunde ukuyisebenzisa. Izinsuku ezimbi zizodlula kanti lokho kuzobe kukhomba ukuthi ingane ayikakulungeli ukusebenzisa ipowa noma ayiyiphathi kahle. Iyeke amasonto ambalwa ubuye uqale uyijwayeze yona.
Ukuchama nokuzikhulula
Ungazitsheli ukuthi ingane izozifundela ngokwayo ukuchama nokuzikhulula. Kungenzeka okunye ikwenze ngaphambi kokunye.
Ukungachami ebusuku
Ukufundisa ingane ukuba ingazichameli ebusuku kuthatha izinyanga ezimbalwa kanti kusazodingeka ukuba ifake amanabukeni uma ilala ngisho noma usuyifundisile. Ongakwenza wukuyijwayeza ukusebenzisa ipowa ngaphambi kokuba ilale.
Izeluleko
Makungakukhathazi okwenziwa ezinye izingane. Fundisa ingane yakho uma ubona ukuthi isikulungele ukufunda.
Bheka ukuthi ayilidonsi yini inabukeni layo njengophawu lokuthi imanzi.
Akulukhuni ukufundisa ingane ukusebenzisa ipowa uma wenza isiqiniseko sokuthi igqoka izingubo ezozikhumula izigqoke kalula.
Uma nihamba, phatha izingubo zengane zokushintsha.
Abafana bakuthola kulula ukuhlala esihlalweni endlini yangasese bachame kunokuchama bemile.
Yigade ingane uma isula izinqe.
Yincome uma isebenzisa ipowa. Ungayithethisi uma ingayisebenzisanga.
Udaba lomunye umama
"Sinenhlanhla ngoba sinengadi encane ekhaya. Kwathi lapho indodana yami isikulungele ukufunda ukusebenzisa ipowa, ngabona kubalulekile ukuba ihlale igqoke okwangaphansi kuphela uma idlala phandle. Kwakuthi uma iphisiwe, ichame engadini. Ukufunda ukusebenzisa ipowa kwaba yinto elula kanti ayixwayanga noma sekufanele ukuba izikhululele kuyona."
OKWABAZALI
Ungakhathazeki uma ubona sengathi ezinye izingane zisheshe zizifunde izinto. Akukho okwedlula ukubekezela ubheke izimpawu zokukhula kwengane. Izokukhombisa uma isikulungele ukwenza izinto...
Bekezela! Uma ingane ikhula, izinto izenza ngezikhathi ezihlukene. Ungakhathazeki uma ingafuni ukuhlala epoweni! Thatha ipowa uyibeke ubuye uzame.

IKALISHI ELISESITAYELENI
UKUTHENGELA ingane yakho ikalishi kungabiza kungabi lula. Uma ungena esitolo esidayisa izinto zezingane ukhangwa amakalishi amaningi ehlukahlukene anamanani ehlukene.
Njengoba ikalishi elinamasondo amathathu kuyilona eliyintandokazi, nakhu okumele ukubheke kulona...
Qhathanisa iminyaka: Bheka ukuthi lakhelwe izingane ezingakanani. Amanye amakalishi awakahle ezinganeni ezinezinyanga ezingaphansi kweziyisithupha.
Ibhekephi?: Kunamakalishi anamasondo amathathu ingane ehlala kuwona ikufulathele. Abanye omama abazwani nalokho.
Bheka amasondo: Ikalishi lihamba kahle uma amasondo emakhulu. Bheka ukuthi amasondo akawudingi yini umoya ukuze angaphantshi.
Maligoqeke kalula: Uma kuzodingeka ukuba ikalishi ulifake ebhuthini yemoto, bheka ukuthi ligoqwa liqaqwe kanjani, ubheke nesisindo salo.
Ubukhulu balo: Ngabe likhulu kangakanani? Abanye omama badinga indawo ikakhulu uma ingane inamathoyizi amaningi, amanabukeni, izikhwama nokunye okumele bakuphathe.
