zulu.1883.career
BONA ZULU - April 2006
ABANTU abadayisa izindawo (estate agents) bahlukile kunabantu abangabadayisi nje. Kufanele babe nekhono elimangalisayo, ulwazi lochwepheshe ukuze bakwazi ukusiza amakhasimende abo lapho kuboniswana ngalokhu.
"Njengoba ama-interest rates kade ephansi kakhulu kule minyaka eminingi edlule nemboni yezokuthengiswa kwezindawo kade ikhombisa okukhulu ukukhula, umsebenzi wokuthengiswa kwezindawo yiwo osungumsebenzi wobuchwepheshe kwabaningi, ezamabhizinisi kanti njengamanje nabasanda kuphuma ezikoleni nasemanyuvesi nabo bafuna ukungena kule mboni ngokwabo," kusho uGrant Gavin, oyi-regional manager yabakwaRE/MAX eKZN nase-Eastern Cape.
"Esikhathini esizayo umphakathi uzobheka izinkampani ezinkulu nalezo ozaziyo futhi ozethembayo. Lezi zinkampani kufanele ziqiniseke ukuthi zinika umphakathi usizo oluphezulu nolusezingeni lobuchwepheshe ukuze zikwazi ukuqophisana nezinye izinkampani.
"Kuzodingeka futhi ukuba kugcizelelwe kakhulu ukuqeqeshwa kwalabo abazoba ngama-estate agents."
USimon Mzobe usebe yi-estate agent kusukela ngoMay nyakenye kanti futhi namanje kuningi asakufunda ngalo msebenzi.
"Ngikholwa wukuthi ngingaphumelela kulo msebenzi wobuchwepheshe," kusho yena. "Nginesisekelo esinzulu kwezezimakethe kanti maduze-nje ngibe nebhizinisi lami lezinhlelo zokuqeqeshela amakhono."
USimon waba nomdlandla kule mboni yezokuthengiswa kwezindawo emva kokuhambela i-workshop yezindawo eyayisingethwe ngabeServices SETA.
"Ngabona ukuthi ukuba yi-estate agent kuzongisiza ngikwazi ukuphatha ibhizinisi lami ngizitholele inzuzo enhle," kuchaza yena.
"Ngenza izifundo zokuqeqeshwa ezathatha cishe izinyanga ezintathu emva kwalokho ngasebenza nowayengifundisa umsebenzi ngaphambi kokuba ngibhekane namakhasimende ngokwami.
"Ngisebenza ezindaweni ezehlukene, ngikhombisa amakhasimende imizi yemali ephezulu naleyo yemali ephansi. Into enhle ngokusebenzela inkampani enkulu wukuthi ngeke ube wedwa. Ngithola usizo olukhulu kwabanye abangama-estate agent kanti sengiyakujwayela futhi ukusebenzisa zonke izinto ezisenkampanini.
"Njengamanje ngidayisa umuzi owodwa ngenyanga. Wonke ama-estate agents ahola ngekhomishini, ngakhoke noma ngubani onothando lokuba yi-estate agent kufanele akwazi ukubekezela cishe izinyanga ezintathu kuya kwezine.
"Angikholelwa enhlanhleni kulo msebenzi. Kufanele uzimisele ngokusebenza kanzima. Kungenzeka kudingeke ukuba uthathe ikhasimende elilodwa uyolikhombisa imizi engaphezu kwewu-12 ehlukene.
"Kufanele futhi uzilungiselele ngokusebenza zikhathi zonke ngoba iningi lamakhasimende lithola isikhathi sokuzobuka imizi ngezikhathi zasemva kwezomsebenzi nangezimpelasonto."
Amathuba
Iningi labantu elingena kulo msebenzi wobuchwepheshe, lingaqala ngokuba lisizane ne-estate agent esinesipiliyoni libe yingxenye yethimba labenza lo msebenzi. Amathuba okuba yizimenenja akhona kulawo ma-estate agents akhombisa impumelelo nokungathi lapho lowo muntu eba nemali akwazi ukuthenga mhlawumbe ingxenye yalelo bhizinisi noma azivulele elakhe.
Amanye ama-estate agents angakhetha ukuba agxile kweminye imisebenzi njengokudayisa izindawo zamabhizinisi nezezimboni, noma zokuqashisa kunothengisa izindlu.
Kufanele ube ngumuntu onjani
Ukuze ube yi-estate agent enempumelelo, udinga lokhu:
PIba nekhono lokuxhumana nabantu.
PUthando lokuwenza kahle umsebenzi wakho.
PUbe nozwelo nokukwazi ukwakha ubuhlobo namakhasimende akho.
PUngesabi ukubizwa ngisho nasebusuku nangezimpelasonto.
PThembeka (ufike ngesikhathi kuma-appointments).
PQonda kahle izidingo zamakhasimende akho.
Okunye okufanele ube nakho: i-cellphone; imoto ethembekile; imali eyanele ukukugcina cishe izinyanga ezintathu, nolwazi lwamakhompyutha.
Ongakuhola
Wonke ama-estate agents asebenzela ikhomishini ngaleyo ndawo eyodwa ayithengisile.
"Nalapho kungathatha ezinye izinyanga eziyisithupha kuya kweziyisishiyagalombili ukuba uthole ikhomishini usudayisile.
"Uma uphethe ibhizinisi lakho, kuyenzeka kube khona izikhathi lapho ungatholi mali izinyanga, kodwa kulokho usizwe mhlawumbe izindlu ezintathu osuzidayisile. Ngakhoke kubalulekile ukuba ukwazi ukusebenzisa noma ukuphatha imali yakho ngokuyikho," kusho uGrant.
Ukuthembela ebuchwephesheni bakho, amahora owachithayo, ikhomishini, ungahola cishe imali esuka ku-R5 000 kuya ku-R30 000 ngenyanga nakuba ngokujwayelekile imali kule mboni ngenyanga ngeke ibe ngaphezulu kuka-R5 000.
Izinga lemfundo/ungafundela kuphi
Njengamanje noma ngubani angabhalisa kwi-Estate Agents Board (EAB) ukuba abe yi-estate agent uma engenawo amarekhodi obugebengu. Abaqeqeshele lo msebenzi bakhuthaza ukuba wonke ama-agents abhale i-exam yabe-EAB ukuze le mboni ihlale isezingeni lobuchwepheshe.
Abafundi ngokuvamile benza izifundo ezigunyazwe ngabe-EAB ezindaweni zabo nokungaba yizifundo ezenziwa ngokugcwele izinsuku ezintathu noma zenziwe amasonto ayisithupha noma ayisikhombisa. Emva kwalokho kubhalwa i-exam enemibuzo eyi-multiple-choice (okhetha impendulo eyiyo kozinikiwe).
Njengengxenye yeBEE abe-RE/MAX lapha eNingizimu yoMzansi we-Africa banezifundo zokuqeqesha ezithatha izinsuku ezingu-90 ngemali exhasiwe. [z]
