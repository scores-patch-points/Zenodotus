Source: MasakhaNER 2.0 (Nigerian Pidgin / Naija, "pcm" split)
Fetched directly from: https://github.com/masakhane-io/masakhane-ner (MasakhaNER2.0/data/pcm/{train,dev,test}.txt)
This is the exact dataset CreoleVal's own nlu/ner/download_masakhaner.sh script fetches -- CreoleVal
does not vendor the raw text in-repo, only the download script and MaChAmp training configs
(nlu/ner/configs/ner_naija.json), so this pocket fetched the real upstream files directly, the
same way CreoleVal's own script would.
