                                         How can get the Loan IQ client installed on my PC?
                                         Create TAC request for installing the Desktop package. Search for "loan" to get the list of
                                         available versions.

                                                                                                                           back to top

                                         How do I get access to the LIQ content in LehmanLive?
                                         Send email to LoaniQ Support with the necessary approvals. tech team will process the
                                         request

                                                                                                                           back to top

                                         How do I get a Loan IQ ledger established?
                                         This is done through a request to the Pathfinder group. Please see LL keyword "Pathfinder"

                                                                                                                           back to top

                                         How do I create a new branch in Loan IQ ?
                                         This will be done by the Pathfinder group as part of the request to set up a new
                                         management code. In order for the Pathfinder group to complete the set up they will require
                                         that a customer is set up within Loan IQ. Please see LL keyword "Pathfinder" for more
                                         details.

                                                                                                                           back to top

                                         How can I setup a branch for sending/receiving payments through GCCM?
                                         Contact GCCM Cash Management to get a new In-house Account created for the branch
                                         and necessary currencies. Work with LoaniQ Support to setup the MIS Code mapping for
                                         the branch in Loan IQ.

                                                                                                                           back to top

                                         How do I submit a new project to Loan IQ Technology?
                                         Open new issue to LoaniQ using JIRA (LL Keyword JIRA. use "GTS Access" in the "JIRA
                                         Instance Access" tab) OR Email completed Project Request Form to LoaniQ IT Dev
                                         Support.
